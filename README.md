# No Fog of War

A tiny [ZombieBuddy](https://github.com/zed-0xff/ZombieBuddy) mod to remove the blackness or "Fog of War" in Project Zomboid.

# Building

> [!NOTE]
> Requirements
> - Gradle
> - Java JDK Supporting Java Version 25
> - ZombieBuddy 2.3.3
## Build Checklist

- Clone the repo
- In `gradle.properties` set the `ZombieBuddyJarPath` property to the location of your `ZombieBuddy.jar`
-  Build the project with: `gradle build` or your IDE of choice.

JAR artifact are placed in `build/libs/`
